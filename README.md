Esse repositório de códigos faz parte do Trabalho de Conclusão de Curso [TCC] do MBA de Data Science da USB Esalq. Autoria: Maycon S. Lacôrte - LinkedIn: https://www.linkedin.com/in/maycon-lacorte-67877611a/

O objetivo deste projeto é avaliar quais fatores socioeconômicos e territoriais estão associados ao desempenho dos estudantes no Enem, utilizando microdados do exame e técnicas modernas de aprendizado de máquina com interpretação baseada em modelos explicáveis.
